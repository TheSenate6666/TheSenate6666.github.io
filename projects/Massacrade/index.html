First-Person Parkour Game

Learning & Academic Project • Unreal Engine 5 • 2024-2026

A first-person parkour experience built in Unreal Engine 5 using the Gameplay Ability System. This project explores dynamic movement mechanics, player feedback systems, and camera design while serving as the practical foundation for my thesis on "invisible tutorials."

Project Overview

This project represents my deep dive into game development with Unreal Engine 5. Built on a foundation of the Gameplay Ability System (GAS), the game focuses on creating an engaging first-person parkour experience with smooth, responsive controls and satisfying player feedback.

Working in a small team environment, I've been responsible for systems design, mechanics implementation, and playtesting feedback loops. The project is also directly integrated with my Bachelor's thesis research on teaching game mechanics through intelligent level design rather than explicit tutorials.

Technical Foundation

Gameplay Ability System (GAS): The core of the game is built on GAS, which provides a robust framework for managing abilities, effects, and gameplay interactions. This allows for flexible, data-driven ability design that scales well as the project grows.

Camera System: Working with my team's custom camera mode stack, I've developed a sophisticated camera system that dynamically responds to player actions and state. The camera is not just a view port but an active feedback mechanism that communicates game state and possibilities to the player.

Movement Mechanics: The parkour movement system includes running, jumping, wall running, climbing, and vaulting. Each ability is carefully tuned to feel responsive and rewarding while maintaining clear visual and audio feedback.

Key Features & Systems

Fluid Movement: Smooth transitions between different movement states with careful attention to input responsiveness and animation blending.

Advanced Camera Modes: Multiple camera configurations that adapt to different movement states, providing optimal player visibility and feedback.

Comprehensive Feedback Systems: Visual, audio, and haptic feedback that reinces successful actions and communicates failures to the player.

Invisible Tutorials: Level design that teaches mechanics through exploration and natural progression rather than explicit instruction screens.

Design Philosophy

The core philosophy behind this project is that great game feel comes from the intersection of responsive controls, clear feedback systems, and thoughtful level design. Every mechanic serves a purpose, and every player action receives immediate, meaningful feedback.

Rather than relying on tutorial screens or pop-ups, the level design guides players naturally through the available mechanics. This "invisible tutorial" approach creates a more immersive and engaging experience while demonstrating advanced level design principles.

Challenges & Solutions

Challenge: Maintaining responsive controls while using the GAS framework, which adds complexity to the input pipeline.

Solution: Careful optimization of GAS ability activation and a custom input buffer system that anticipates player input, creating the feeling of tight, responsive controls.

Challenge: Creating a camera system that provides good visibility for parkour action while remaining predictable and controlable.

Solution: Multiple camera modes that activate based on movement state, allowing the camera to be context-aware while remaining player-controllable.

Technical Details

Engine: Unreal Engine 5.5 - 5.7
Primary Language: Blueprint (with C++ for core systems)
Key Systems: Gameplay Ability System, Enhanced Input System, Camera Mode Stack
Team Size: Small team with specialized roles
Status: Active development
Timeline: Ongoing as part of academic curriculum and professional development

Key Learnings

GAS Mastery: Deep understanding of how to leverage the Gameplay Ability System for complex, multiplayer-ready ability design.

Feedback Design: The critical importance of multi-layered feedback (visual, audio, haptic) in creating game feel.

Team Collaboration: Working within a team structure to integrate different systems and maintain consistent vision.

Level Design Principles: How to teach complex mechanics through environmental design and player affordances.

Iterative Polish: The importance of continuous playtesting and refinement in achieving professional-level game feel.
